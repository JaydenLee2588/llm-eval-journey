## 📝 题目 1：测试集 Prompt 文本清洗
* **考察知识点**: `strip()`、`split()`、`replace()`、字符串切片 `[::-1]`
* **背景**: 在评测任务中，从外部测试集或日志读入的 Prompt 往往带有多余的换行、空格及角色标签。
* **输入**:
  ```python
  raw_prompt = "  \n  User: What is the capital of France!?  \n  "
  ```
* **要求**:
  1. 去除首尾的空白字符和换行符；
  2. 提取出冒号后面的纯提问文本（去掉 `"User: "`）；
  3. 将句尾多余的 `!?` 替换为标准的单个 `?`；
  4. 最终全部转换为小写；
  5. 使用切片 `[::-1]` 打印出翻转后的文本。

## 📝 题目 2：评测得分计算与精度判断
* **考察知识点**: 浮点数精度存储机制、`math.isclose()`、三元表达式
* **背景**: LLM 文本匹配评测中计算了两项子指标得分（如 BLEU 与 ROUGE 的加权分值）。
* **输入**:
  ```python
  score_a = 0.1
  score_b = 0.2
  ```
* **要求**:
  1. 分别用两种方式（f-string 格式化、`round()` 函数）将 `score_a + score_b` 保留 2 位小数展示；
  2. **不能**直接用 `== 0.3`。请使用标准库判断两者之和是否在浮点数误差内约等于 `0.3`；
  3. 使用**单行三元表达式**将比对结果转换为状态描述：若符合预期赋值 `"得分正常"`，否则赋值 `"计算异常"`，并打印。

## 📝 题目 3：评测用例执行状态分类
* **考察知识点**: `enumerate()`、`match-case` 模式匹配、多值匹配 `|`
* **背景**: 模型批量推理结束后，需要给每一条用例打上序号并做状态分流。
* **输入**:
  ```python
  case_statuses = ["SUCCESS", "TIMEOUT", "FAILED", "SUCCESS", "BAD_GATEWAY"]
  ```
* **要求**:
  1. 使用 `enumerate` 遍历列表，用例编号从 **1** 开始计数；
  2. 在循环中使用 `match-case` 判断并打印对应提示：
     - 若为 `"SUCCESS"`：打印 `Case #序号: 通过`
     - 若为 `"TIMEOUT"` 或 `"FAILED"`（使用 `|` 匹配多个）：打印 `Case #序号: 需人工排查`
     - 若为其他未知状态（通配符 `_`）：打印 `Case #序号: 异常状态待定`

## 📝 题目 4：压测中断与缓存跳过
* **考察知识点**: 循环流程控制 `break`、`continue`、`for ... else`
* **背景**: 对大模型推理延迟（毫秒 ms）进行压力监控，当遇到极端超时需触发熔断。
* **输入**:
  ```python
  latencies = [120, 30, 180, 25, 650, 90, 110]
  ```
* **要求**:
  1. 遍历 `latencies` 列表：
     - 如果耗时 `< 50ms`（判定为命中缓存），使用 `continue` 跳过本次，不打印；
     - 如果耗时 `>= 500ms`（严重超时告警），打印 `"⚠️ 发现严重超时 [{latency}ms]，熔断退出！"` 并用 `break` 立即终止整个循环；
     - 其余正常耗时，打印 `"推理完成，耗时: {latency}ms"`；
  2. 利用 Python 特有的 `for ... else` 语法：如果所有用例均未触发熔断（即循环自然结束，未被 break 强行中断），则打印 `"🎉 压测完成，未发生熔断"`。（提示：可尝试将数据中的 650 改为 150 验证 else 分支的效果）。

## 📝 题目 5：提取严重 Bad Case 标签
* **考察知识点**: 列表推导式、`startswith()`、字符串截取/替换、`join()`
* **背景**: 评测结束后需要从所有错误标签中快速筛选出所有的严重漏洞（Critical Issues）。
* **输入**:
  ```python
  tags = ["CRITICAL_hallucination", "WARN_slow", "CRITICAL_prompt_leak", "INFO_token_overflow", "CRITICAL_jailbreak"]
  ```
* **要求**:
  1. 用**列表推导式**筛选出所有以 `"CRITICAL_"` 开头的标签；
  2. 在推导式或后续处理中，将 `"CRITICAL_"` 前缀去掉，只保留纯问题类别（即得到 `['hallucination', 'prompt_leak', 'jailbreak']`）；
  3. 使用 `join` 方法，将提取出的问题类型用 `" | "` 拼接成一行摘要字符串打印出来（期望输出：`hallucination | prompt_leak | jailbreak`）。
